# Sutra: бесплатные и платные опции, цены, подписки

Приложение **Sutra** сейчас — офлайн CRM для партнёра: клиенты, покупки, касания, справочники, утренние уведомления. Ни монетизации в коде, ни paywall нет — ниже логика вариантов и ориентиры по рынку.

## Бесплатно / платно: разумные границы

### Оставить бесплатно (чтобы скачивали и привыкли)

- Карточки клиентов, воронка статусов, покупки и автокалендарь 0–3–7–15
- Справочники продуктов и запросов
- Экран «Сегодня», просрочка
- Локальные утренние уведомления
- Один язык, базовый объём данных (например до 30–50 клиентов)

### Платно или по подписке

- **Синхронизация / бэкап** (облако, второе устройство) — главный драйвер, когда появится Supabase/PowerSync
- **Экспорт** (Excel/CSV, отчёт за период)
- **Без лимита** клиентов или расширенная аналитика
- **Несколько «витрин»/каталогов** или несколько пользователей (если появится команда)
- **Кастомизация касаний** (свои дни, шаблоны SMS)
- **White-label** / бренд для лидеров сети — B2B, не массовый сегмент

Для соло-партнёра честнее: **ядро бесплатно**, платят за **облако, резерв и «не потерять базу»**, а не за «ещё одну кнопку».

## Разовая покупка vs подписка

| Модель | Когда уместно |
|--------|----------------|
| **Разовая** (300–1500 ₽ в RuStore) | Мало инфраструктуры, нет сервера, редкие обновления |
| **Подписка** (99–399 ₽/мес или 699–2499 ₽/год) | Есть облако, синк, поддержка, постоянные доработки |
| **Freemium** | Бесплатно локально, подписка только на sync/backup/export |

Для текущего стека (SQLite, sync «потом») на старте часто делают **бесплатно + разовый Pro** или **бесплатно + недорогая годовая подписка**, когда появится облако.

## Сколько стоят «похожие» приложения (очень грубо)

Точной категории «CRM партнёра MLM в RuStore» почти нет; ориентиры:

- **Простые CRM/задачники для малого бизнеса**: 0 ₽ с рекламой или **~200–800 ₽** разово; подписка **~150–500 ₽/мес**
- **Западные CRM для соло**: **$10–25/мес**, у нас реже покупают без локализации
- **Узкие нишевые приложения в RuStore**: часто **бесплатно** или **299–990 ₽** разово; подписки слабее, если нет явной «облачной» ценности

В нишу попадает: **чувствительные телефоны + офлайн**. Люди чаще платят за **надёжность и бэкап**, не за «ещё одну CRM».

## Практичная схема для Sutra (поэтапно)

1. **Сейчас**: всё бесплатно, сбор отзывов, RuStore, без paywall.
2. **После sync**: Free = только телефон; **Pro** = облачный бэкап + второе устройство — **~199–349 ₽/мес** или **~1490–1990 ₽/год** (скидка 20–30%).
3. **Опционально разово**: **Pro lifetime** **~1990–3990 ₽** только если затраты на сервер малы (иначе lifetime «съедает» подписку).

Юридически: оферта, политика ПДн; при облаке — отдельно про хранение телефонов.

## Что выбрать

- **Только платное** без бесплатной версии — для RuStore обычно **хуже**: мало скачиваний, нет сарафана.
- **Только подписка** — уместна **после** облака; до появления sync подписка «за локальную CRM» слабо продаётся.
- **Бесплатно + платный sync/backup** — лучше всего стыкуется с текущей архитектурой и страхом «потерять базу».
